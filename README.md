# Retail Sales Analytics Data Pipeline

## Overview

This project demonstrates an end-to-end Data Engineering pipeline using Python, PySpark, SQL, and Power BI.

The pipeline ingests retail sales data, performs data quality checks, transforms data using PySpark, models data into a Star Schema, and generates business insights through SQL analytics and dashboards.
