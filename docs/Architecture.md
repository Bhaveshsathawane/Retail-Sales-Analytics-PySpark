# Retail Sales Analytics Data Pipeline

## Objective

Build an end-to-end Data Engineering pipeline that processes retail sales data using Python, PySpark, SQL, and Power BI.

---

## Architecture

Raw Dataset
    ↓
Data Validation
    ↓
PySpark Transformation
    ↓
Star Schema Modeling
    ↓
SQL Analytics
    ↓
Power BI Dashboard

---

## Technologies

- Python
- PySpark
- SQL
- Power BI
- Git
- GitHub

---

## Data Model

Fact Table:
- FactSales

Dimension Tables:
- DimCustomer
- DimProduct
- DimDate
